Nama Proyek: Kakila Web Link Aggregator & Catalog
Tujuan Proyek: Menyediakan multi-step landing page yang ringan, responsif, dan elegan untuk mengarahkan audiens media sosial ke produk afiliasi (Shopee/TikTok) dan produk digital e-book, dilengkapi sistem pencarian kode produk yang cepat.

A. Scope & Features (Frontend Focus)

Multi-Step Navigation System:

Phase 1 (Linktree View): Tampilan awal berisi profil, bio, dan tombol akses utama (E-Book, Shopee, TikTok Shop).

Phase 2 (Catalog View): Menampilkan grid produk sesuai platform yang dipilih di Phase 1.

Smart Search (Client-Side):

Fitur pencarian real-time berdasarkan product_code di halaman katalog.

Admin Dashboard (UI Only):

Halaman statis /admin untuk manajemen CRUD produk (form input, opsi dropdown platform, area upload gambar).

B. Tech Stack Assumptions

Framework: React (direkomendasikan menggunakan Next.js App Router untuk kemudahan routing ke /admin).

Styling: Tailwind CSS (paling optimal untuk vibe coding bersama AI).

State Management: React Hooks (useState untuk navigasi antar Phase).
